# Tetris на Go

Тетрис на Go с [Ebitengine](https://ebitengine.org).

## Запуск

```bash
go run .
```

Сборка бинарника:

```bash
go build -o tetris
./tetris
```

## Управление

| Клавиша | Действие                                   |
| ------- | ------------------------------------------ |
| ← →     | Двигать фигуру (при удержании повторяется) |
| ↑       | Повернуть по часовой стрелке               |
| Z       | Повернуть против часовой стрелки           |
| ↓       | Ускорить падение (+1 очко за клетку)       |
| Пробел  | Мгновенно уронить (+2 очка за клетку)      |
| P       | Пауза                                      |
| R       | Начать заново после проигрыша              |

## Правила

- Очки за линии: 1 — 100, 2 — 300, 3 — 500, 4 — 800.
- Каждые 5 линий уровень растёт, и фигуры падают быстрее.
- Фигуры выдаются «мешком» по семь штук, поэтому каждая встречается равномерно.
- Серый контур показывает, куда упадёт фигура.
- Поворот у стены сдвигает фигуру на 1–2 клетки, если на месте не помещается.

## Лучший счёт

Хранится в текстовом файле в папке настроек пользователя:

- macOS: `~/Library/Application Support/tetris/highscore.txt`
- Linux: `~/.config/tetris/highscore.txt`
- Windows: `%AppData%\tetris\highscore.txt`

Чтобы сбросить рекорд, удалите этот файл.
